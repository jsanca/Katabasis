# Adversarial Analysis

This canonical OSK package makes engineering review adversarial in a precise sense: it tries to falsify a stated claim by identifying assumptions, designing counterexamples, and tracing plausible failure mechanisms.

It complements, rather than replaces, architecture review, boundary review, and verification engineering. It does not authorize destructive security testing, live probing, or unsafe payloads.

Use [SKILL.md](SKILL.md) as the operating contract.
