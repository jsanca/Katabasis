# Project Roadmap

## Purpose

Store the project's forward-looking direction.

## What belongs here

Committed milestones, planned work, capability evolution, planned releases, longer-term technical direction, and future ideas that are clearly identified as non-committed.

**Example:** Put “add event replay next quarter” here. After implementation, document how replay works in `../knowledge/` and retain its delivery evidence in `../engineering/`.

## What does not belong here

Completed engineering evidence or current system documentation. Link those records rather than duplicating them.
