# Agent Reports

## Purpose

Store durable, evidence-based completion reports for non-trivial implementation, documentation, research, fix, recovery, and audit work.

## What belongs here

Reports named `<task-id>-<lowercase-slug>.md` when a task ID is available. Include objective, files changed, evidence, validation, limitations, follow-up, and related records.

## What does not belong here

The compact engineering index, review-only records, or open recovery state. Link every material report from `../../ENGINEERING_LOG.md`.
