# K-0.2-T08 — CLI Exit Codes & Structured Error Output Report

## Status

Complete

## Objective

Define, implement, and verify a stable CLI exit code contract and predictable structured error
output for all download scenarios.

## Design

### Exit Code Contract

Defined in `CliExitCode`:

| Code | Constant | Scenario |
|------|----------|----------|
| 0 | SUCCESS | All downloads completed |
| 1 | EXECUTION_FAILURE | Any failure, all-failed batch, or input error |
| 2 | USAGE_ERROR | Invalid CLI arguments or configuration (picocli returns 2 for missing args before `call()`) |
| 3 | PARTIAL_BATCH_FAILURE | Mixed batch outcome — some succeeded, some failed |

Exit code 3 is a new code not present in earlier CLI work. `TC-CLI-LIST-002` previously asserted
exit 1 for partial batch failure; that test was updated to assert exit 3 and given an explanatory
Javadoc comment documenting the compatibility decision.

### Structured Error Format

All errors emitted via `CliErrorFormatter.formatError()`:

```
ERROR code=<CODE> [downloadId=<ID>] [source=<URI>] message="<ESCAPED>"
```

- `downloadId` and `source` are omitted when null (pre-submission failures, internal errors)
- `source` has userinfo (user:password@host) stripped via `sanitizeUri()` before output
- `message` is always present and double-quoted
- Escape sequences: `\` → `\\`, `"` → `\"`, CR → `\r`, LF → `\n`, TAB → `\t`

Batch summary emitted on stdout via `CliErrorFormatter.formatSummary()`:

```
SUMMARY total=N completed=M failed=K cancelled=0 rejected=0
```

### Credential Safety

`CliErrorFormatter.sanitizeUri()` strips the `userinfo` component (user:password@host) before
writing any URI to stderr. It rebuilds the URI with `new URI(scheme, null, host, port, path,
query, fragment)` and falls back to `scheme://host/path` for non-hierarchical URIs.

### stdout/stderr ownership

- Progress output: stdout
- Download completion messages: stdout
- Batch summary: stdout
- All errors (DOWNLOAD_FAILED, DOWNLOAD_CANCELLED, DOWNLOAD_REJECTED, INTERNAL_ERROR): stderr

### Compatibility

`DownloadListCommandTest.TC-CLI-LIST-014` and `TC-HARDEN-B-002` were updated from the old
`"Done: N completed, M failed."` summary format to the new `SUMMARY total=...` format.
