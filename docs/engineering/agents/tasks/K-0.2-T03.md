# K-0.2-T03 — Add AutoCloseable to DownloadManager; Implement Graceful Shutdown

## Status

DONE

## Goal

Add `AutoCloseable` to the `DownloadManager` public API and implement graceful shutdown in
`DefaultDownloadManager`. Shutdown must:

1. Stop accepting new downloads (throw `DownloadRejectedException`).
2. Signal all active and paused downloads to terminate cooperatively.
3. Wait for the executor to drain (bounded at 10 seconds).
4. Suppress `DownloadCancelledEvent` for downloads stopped by shutdown (not user-initiated).
5. Be safe and idempotent for concurrent and repeated callers.
