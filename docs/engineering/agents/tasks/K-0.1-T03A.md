## Objective

Determine the JSON technology already available in Katabasis and select the smallest reliable solution for versioned JSON serialization of download snapshot structures.

## Authorized Scope

- Inspect Maven POMs, effective dependency tree, and JPMS module-info files
- Evaluate Jackson (if present) and Jakarta JSON-B + Yasson
- Verify compatibility with Java 25 records, nested records, enums, immutable collections, nulls, JPMS
- Create minimal round-trip test
- Document decision; do not implement storage or versioning

## Acceptance Criteria

- Actual dependency tree inspected
- Exactly one JSON binding selected
- Java 25 records round-trip proven by automated test
- JPMS compatibility verified
- No JSON framework types in Katabasis domain APIs
