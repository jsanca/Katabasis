# K-0.2-T10 — Storage Wiring & Consistent Checkpoints

## Objective

Wire persistent checkpoints into the active download execution path so that a real HTTP
download produces a versioned JSON manifest containing trustworthy recovery metadata:
segment boundaries, ETag, and confirmed bytes at the moment of snapshot.
