## Objective

Verify whether the event-storm risk (R-001) identified in the planning report is real: that `SegmentedHttpDownloadStrategy` emits N `DownloadPausedEvent` + N `DownloadResumedEvent` per pause/resume signal (one per chunk thread). If confirmed, fix the behavior so exactly one event of each type is emitted regardless of segment count. Add a regression test.

## Authorized Scope

- Read `PauseCoordinator.awaitIfPaused()` to understand the root cause
- Fix `SegmentedHttpDownloadStrategy` if confirmed
- Add test to `SegmentedHttpDownloadStrategyTest`
- No changes to `PauseCoordinator`, `HttpDownloadStrategy`, or public API
