# K-0.2-T08 — CLI Exit Codes & Structured Error Output

## Objective

Define, implement, and verify a stable CLI exit code contract and predictable structured error
output for all download scenarios in both `download` and `download-list` subcommands.

## Exit Code Contract

| Code | Constant | Meaning |
|------|----------|---------|
| 0 | `SUCCESS` | All downloads completed successfully |
| 1 | `EXECUTION_FAILURE` | Download failed, cancelled, or input was invalid |
| 2 | `USAGE_ERROR` | Invalid CLI arguments or configuration |
| 3 | `PARTIAL_BATCH_FAILURE` | Some downloads succeeded, some failed (batch only) |

## Structured Error Format

Errors are written to stderr in a machine-parseable format:

```
ERROR code=DOWNLOAD_FAILED downloadId=abc123 source=https://example.com/file.zip message="Connection timed out"
```

Batch summary is written to stdout at the end of each `download-list` run:

```
SUMMARY total=3 completed=1 failed=2 cancelled=0 rejected=0
```
