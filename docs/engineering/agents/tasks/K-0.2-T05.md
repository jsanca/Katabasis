# K-0.2-T05 — CLI URL List Downloads

**Phase:** 0.2 — CLI & Persistence
**Type:** Feature
**Status:** DONE
**Date:** 2026-11-11
**Depends on:** K-0.2-T04

## Objective

Implement `katabasis download-list <url-list-file> --output-dir <directory>` — a CLI subcommand that downloads all URLs listed in a file to a target directory, sharing a single `DownloadManager` and tracking per-file outcomes via event correlation.

## Scope

### New production classes — `katabasis-cli`

- **`UrlListParser`** — parse a UTF-8 URL list file; skip blank lines and `#` comments; validate every non-blank line as an absolute URI before returning any entries; throw `ParseException` with accumulated per-line error messages on any failure.
- **`OutputFilenameResolver`** — derive a safe output filename from a URI path segment (strip query/fragment, URL-decode via `URI.getPath()`, last segment after trailing-slash stripping); normalize under output dir and verify no path traversal; throw `IllegalArgumentException` on any violation.
- **`DownloadListCommand`** — picocli `@Command(name = "download-list")`; positional `Path urlListFile`; required `--output-dir`/`-d` option; single `DownloadManager`; `CountDownLatch(N)`, `ConcurrentHashMap<downloadId, Boolean>` for event correlation; per-file status lines to stdout/stderr; final summary line.

### Modified

- **`KatabasisCommand`** — add `DownloadListCommand.class` to `subcommands`.

### Tests

14 integration tests in `DownloadListCommandTest` (TC-CLI-LIST-001 through TC-CLI-LIST-014) using an in-process `TestHttpServer`.

## Constraints

- Pre-validate all entries (parse + filename resolution + duplicate detection) before submitting any `manager.download()` call.
- No silent overwrite: reject duplicate output filenames before any download begins.
- Create the output directory if it does not exist (`Files.createDirectories`).
- Exit 0 iff all downloads completed. Exit 1 for any failure, invalid input, or cancellation. Exit 2 for picocli argument errors.
- Do not modify `katabasis-core`, `pom.xml`, or module-info.java.
