# K-0.2-T06 — CLI Configuration & Execution Controls

## Objective

Expose existing `DownloadManager` configuration through the Katabasis CLI so users can control segment count, retry policy, HTTP timeouts, and batch concurrency from the command line.

## Deliverables

- `DownloadConfigMixin.java` — picocli mixin with `--segments`, `--retries`, `--connect-timeout`, `--response-timeout`, `--read-timeout`
- `CliDurationConverter.java` — picocli `ITypeConverter<Duration>` for user-friendly duration strings
- `DownloadCommand.java` — wired to mixin; `Supplier` → `Function<DownloadConfig, DownloadManager>` factory
- `DownloadListCommand.java` — wired to mixin; added `--max-concurrent` option
- `CliDurationConverterTest.java` — 14 unit tests for the duration converter
- `DownloadConfigOptionsTest.java` — 12 integration tests (TC-CFG-001 through TC-CFG-012)
